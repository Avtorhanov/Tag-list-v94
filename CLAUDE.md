# Tag list — правила для Claude Code

Офлайн-помощник инженера КИПиА: тэг-лист приборов с заданиями, отметки «выполнено», отчёт в рабочий чат, конверторы «Газ», «4–20 мА», «Электроэнергетика», распознавание тегов с фото без интернета. Основной пользователь работает с iPhone (PWA на GitHub Pages), для Android собирается APK. Описание функций для людей — в `README.md`.

Общение с пользователем, комментарии в коде, коммиты и PR — на русском.

## Жёсткие правила

- **Не пушить в `main`.** Ветка `claude/vNNN-краткое-имя` → PR → мердж делает пользователь. Мердж в `main` = релиз: GitHub Pages обновляет сайт, `.github/workflows/build-apk.yml` собирает APK.
- **Версии.** Каждая фича или исправление — следующий номер `vNNN` (смотри `CACHE_NAME` в `sw.js`). В коде изменения помечаются комментарием `// vNNN: что сделано`. Заголовок PR: `vNNN: кратко`.
- **`sw.js`.** При изменении любого кэшируемого файла поднять `CACHE_NAME` (`vNNN-1`) и дописать в комментарий строки, что изменилось. Новый файл — добавить в список кэша, иначе офлайн он не откроется.
- **Данные пользователя живут на телефоне** (localStorage + IndexedDB `tag-list-photos`). Любое изменение формата — только с миграцией старых данных; ничего не терять.
- **Без сборки и зависимостей.** Чистый HTML/CSS/JS, никаких npm-пакетов, бандлеров и CDN: приложение обязано работать офлайн. Сторонние библиотеки кладутся файлами в `js/vendor/` вместе с лицензией.
- **Лицензии не удалять** (`LICENSE`, `js/ocr-local/LICENSE-Tesseract.txt`, `js/ocr-pp/LICENSE-PaddleOCR.txt`, `js/vendor/LICENSE-*.txt`, `css/fonts/LICENSE-IBM-Plex.txt`). Первые строки `README.md` не трогать.
- **Тексты интерфейса** — через `TX("…")`; для каждой новой русской строки добавить перевод в `js/i18n-en.js`.
- Ключи подписи APK — только в секретах GitHub, в репозиторий не попадают.

## Структура

- `index.html` — вся разметка и окна. Подключает по порядку: `i18n.js`, `i18n-en.js`, `tag-format.js`, `tag-photos.js`, `tag-camera.js`, `app.js`.
- `js/app.js` (~5600 строк) — страницы, список, задания, импорт (камера, фото, файл, вставка), пакет до 20 фото с обрезкой и выравниванием, отчёт, JSON-состояние. Модель тега: `{id, unit, tag, done, task, photos?}`.
- `js/tag-format.js` — форматы тегов (ISA-5.1, KKS, свой образец).
- `js/tag-photos.js` — фото к заданию (IndexedDB). `js/tag-camera.js` — серийная съёмка.
- `js/ocr-local.js` + `js/ocr-local/` — Tesseract WASM, модели rus + eng; подгружается из `app.js` при первом распознавании.
- `js/ocr-pp.js` + `js/ocr-pp/` — второй локальный движок, нейросеть PP-OCRv5 (детектор строк + распознаватель eslav, `worker.js`); считает ONNX Runtime Web 1.18.0 из `js/vendor/` (`ort.wasm.min.js`, `ort-wasm-simd.wasm`). Выбирается тумблером «Tesseract / OCRv5» в строке под заголовком меню «Добавить тэг» и сегментом в окне фото (`kipLocalOcrModel`, по умолчанию OCRv5), подгружается из `app.js`. Происхождение и контрольные суммы файлов — `js/ocr-pp/SOURCES.txt`; версию ONNX Runtime без проверки в APK и на iPhone не менять (с 1.19 запуск устроен иначе).
- `js/gas.js`, `js/loop.js`, `js/elec.js` — конверторы; подгружаются из `app.js` при открытии раздела.
- `js/vendor/xlsx.full.min.js` — разбор Excel, подгружается при импорте файла; там же ONNX Runtime Web для OCRv5.
- `css/app.css` — стили и 4 темы.
- `android/` — оболочка WebView: мост `window.AndroidApp`, системная «Назад» через `window.__tagListBack`.

## Перед началом работы

- Состояние проекта, решения пользователя и идеи — в claude.ai-проекте «Tag list», документ `claude/00-START.md`. После влития PR обновить в нём строку «Состояние».
- Ветки после влития удаляются; в репозитории должны оставаться только `main` и открытые PR.

## Проверка перед PR

Автотестов в репозитории пока нет — проверять самому и писать в PR, что именно проверено.

- Синтаксис каждого изменённого файла: `node -e "new Function(require('fs').readFileSync('js/app.js','utf8'))"`.
- В браузере: Playwright + Chromium, экран 390×844, `is_mobile`, `has_touch`. Заставку отключить: `sessionStorage 'tl-splash'='1'`. Сервер `python3 -m http.server` запускать в той же команде, что и тест.
- Камера: флаги `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream` и `grant_permissions(["camera"])`.
- Режим APK: до загрузки страницы задать `window.AndroidApp=new Proxy({},{get:(t,k)=>()=>''})`.
- Проверять обе ветки поведения там, где они расходятся: iPhone (PWA) и Android (APK), RU и EN.
- Замеры распознавания — только на реальных фото бирок; если их нет в сессии, попросить пользователя приложить.

## Как писать PR

Тело PR: что изменилось для пользователя, что проверено, что нужно проверить на телефоне. Создание через REST:

`gh api repos/Avtorhanov/Tag-list-v94/pulls -X POST -f title=... -f head=... -f base=main -F body=@file.md`
