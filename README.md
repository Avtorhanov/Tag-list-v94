# Tag list

Карманный помощник инженера КИПиА на большом объекте: тэг-лист приборов с заданиями, конверторы «Газ» и «4–20 мА» и отчёт в рабочий чат в пару касаний. Для импорта тэгов из фото и камеры требуется интернет с VPN, весь остальной функционал локальный.

## Тэг-лист

- **Работа раскладывается сама.** Вкладки по установкам строятся из первых четырёх цифр тега (`2131-…`, `2140-…`) со счётчиками, рядом — «Задания», «Выполненные», «Невыполненные». Страницы — отдельные списки: по установке, смене или системе.
- **Список не нужно набирать.** Фото бумажного перечня или бирок (OCR), файл XLSX / XLS / CSV / TXT или текст из письма и мессенджера. Тег находится в любом месте строки, остаток строки становится заданием, `✓` `+` `да` `done` — отметкой «выполнено», следующая строка без тега дописывается к заданию.
- **Ошибки распознавания исправляются.** O→0, I→1, S→5, тег сверяется с уже существующими (разница в один символ) — дубли не появляются.
- **Массовые действия.** Удержать карточку → выбрать несколько → «Выполнено», «Удалить» или ⧉ — копировать теги с заданиями.
- **Отчёт в группу.** По странице: весь список, выполненные, невыполненные или задания — текстом через «Поделиться» либо на весь экран («Сухой список») для планёрки. Всё состояние — файлом `.json` на другой телефон; перед открытием создаётся резервная копия.

## Конверторы

- **Газ** — ppm ⇄ мг/м³ ⇄ % об. ⇄ % НКПР ⇄ 4–20 мА с поправкой на температуру и давление. Около 30 веществ: пиролиз, ПЭ/ПП, ароматика, H₂, H₂S, NH₃, CO и др. НКПР — по ГОСТ 31610.20-1 (можно вписать из паспорта прибора), доля ПДК р. з., свой газ для смесей.
- **4–20 мА** — TT (Pt / П / М, R₀, ГОСТ 6651), PT (МПа, кгс/см², бар, psi, мм вод. ст.), FT по перепаду с корнем в датчике или в РСУ, LT прямой или гидростатикой (ρ, смещение). Ввод в любое поле пересчитывает остальные; тип прибора — по тегу (`2131-TT-434` → TT); точки поверки 0/25/50/75/100 %; состояние сигнала по NAMUR NE 43.
- **«В задание»** — результат с датой и временем дописывается в задание тега (тег ищется на всех страницах, если его нет — создаётся) и уходит в отчёт.
