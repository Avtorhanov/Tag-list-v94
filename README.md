# Tag list

**Tag list** — лёгкое веб-приложение для работы со списками тегов.

### Возможности

- Адрес https://avtorhanov.github.io/Tag-list-v94/

- 📋 Создание и редактирование списков тегов.
- 📷 Добавление тегов из фотографии через OCR.
- ☑️ Отметка выполненных и невыполненных тегов.
- 📝 Добавление заданий к отдельным тегам.
- 📤 Показ и отправка:
  - всего списка;
  - выполненных;
  - невыполненных;
  - заданий.
- 🔤 Изменение размера и типа шрифта.
- 🌙 Переключение темы.
- 📄 Работа с несколькими страницами.
- 💾 Автоматическое сохранение данных в браузере.
- 📱 Адаптация для **iPhone и Android**.
- 📲 Возможность установить приложение на главный экран как PWA.

### Принцип работы

Приложение работает непосредственно в браузере.  
Основные данные сохраняются локально на устройстве, поэтому список можно использовать без постоянной регистрации или серверной базы данных.

### Назначение

Проект предназначен прежде всего для **быстрой работы с перечнями приборов и оборудования КИПиА** при монтаже, проверке и пусконаладочных работах.
## Обновление JSON-состояний и мобильного интерфейса
- Импорт JSON выполняется внутри приложения через «Сохранить / отправить» → «Открыть JSON»; после успешной проверки состояние сразу применяется.
- Перед заменой текущая версия сохраняется в локальном резервном ключе `kip-checklist-last-state-backup-v1`, без дополнительной загрузки резервного файла, которая мешала мобильному выбору файла.
- Отправка JSON сначала пробует системный обмен файлами, затем обмен текстом JSON, а при недоступности этих способов сохраняет файл.
- Для установленных Android Chromium PWA добавлен обработчик открытия `.json` из системного файлового менеджера. Поддержка такого открытия зависит от браузера и установки PWA; на iPhone используйте импорт внутри приложения.
- Нижняя панель выбора тегов теперь появляется выдвижением снизу; системная настройка уменьшения движения учитывается.
