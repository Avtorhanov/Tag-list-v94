# Tag list

Карманный помощник инженера КИПиА на большом объекте: тэг-лист приборов с заданиями, конверторы «Газ», «4–20 мА» и «Электроэнергетика» и отчёт в рабочий чат в пару касаний. Всё работает без интернета, включая распознавание тэгов с фото; онлайн-распознавание OCR.space (нужны интернет и VPN) — по желанию, для сложных снимков.

## Тэг-лист

- **Работа раскладывается сама.** Вкладки по установкам строятся из номера установки в теге (`2131-PT-102` → «2131», `21-PT-1001` → «21») со счётчиками, рядом — «Задания», «Выполненные», «Невыполненные». Страницы — отдельные списки: по установке, смене или системе.
- **Список не нужно набирать.** «Добавить» → Камера, Фото, Файл или Вставить: фото бумажного перечня или бирок, файл XLSX / XLS / CSV / TXT (кнопка сразу открывает выбор файла) или текст из письма и мессенджера — «Вставить» сразу берёт его из буфера обмена. Окно с найденными тегами тянется за ручку сверху — на весь экран или на половину. Тег находится в любом месте строки, остаток строки становится заданием, `✓` `+` `да` `done` — отметкой «выполнено», следующая строка без тега дописывается к заданию.
- **Любой формат тегов.** Кнопка `ISA-5.1` рядом с тумблером OCR в окне «Добавить»: **ISA-5.1** с переключателем «Установка: любая / есть / нет» (`2131-PT-102`, `21-PT-1001`, `PT-101`), **KKS** для электростанций (`10LBA10CP001`) или **свой образец** — вписать тег из своего списка, правило построится само. Под полем «Тег» сразу видно, подходит ли тег и в какую вкладку попадёт; в меню формата — «Проверить на тексте» с подсветкой и справка по обозначениям ISA-5.1. Не считаются тегами насосы и ёмкости (`P-101`, `V-201`), `DN`/`PN`, номера документов, `IP65`, `Pt100`. Выбор хранится на телефоне.
- **Ошибки распознавания исправляются.** O→0, I→1, S→5, тег сверяется с уже существующими (разница в один символ) — дубли не появляются.
- **Массовые действия.** Удержать карточку → выбрать несколько → «Выполнено», «Удалить» или ⧉ — копировать теги с заданиями.
- **Отчёт в группу.** Кнопка «Отчёт» в верхней строке: одна или несколько страниц, выполненные, невыполненные или всё, с заданиями или без, исполнители из контактов телефона или вписанные вручную (на iPhone выбор из телефонной книги открывается после включения Contact Picker API: Настройки → Safari → Дополнения → Feature Flags; без него iPhone подсказывает имена при вводе). Окно на весь экран с большим полем текста и кнопкой «Отправить», которая всегда внизу и над клавиатурой; двойное касание по тексту — правка на весь экран, правки не пропадают при смене выбора. Прежние варианты — текстом через «Поделиться» либо на весь экран («Сухой список») для планёрки. Всё состояние — файлом `.json` на другой телефон; перед открытием создаётся резервная копия.

## Распознавание фото без интернета

- **На телефоне.** Tesseract 5 (WebAssembly) с моделями rus + eng лежит в приложении (`js/ocr-local/`, ~16 МБ): в APK — сразу, в веб-версии — после первого открытия. Фото не покидает устройство.
- **Выделение участка.** Значок в углу фото — рамка как в галерее телефона: углы и стороны тянутся, рамка двигается, раздвигается двумя пальцами.
- **Длинные перечни.** Узкий скриншот увеличивается, длинный список читается полосами, строки таблицы собираются по положению слов, теги дочитываются отдельным проходом. Скриншот перечня на 108 строк — 107 тегов с заданиями.
- **OCR.space.** Тумблер рядом с заголовком «Добавить» и в окне фото включает онлайн-распознавание (Engine 3, при сбое Engine 2): выпадает строка «Включите сеть и VPN» с проверкой связи, снимок уходит на сервер.

## Конверторы

- **Газ** — ppm ⇄ мг/м³ ⇄ % об. ⇄ % НКПР ⇄ 4–20 мА с поправкой на температуру и давление. Около 30 веществ: пиролиз, ПЭ/ПП, ароматика, H₂, H₂S, NH₃, CO и др. НКПР — по ГОСТ 31610.20-1 (можно вписать из паспорта прибора), доля ПДК р. з., свой газ для смесей.
- **4–20 мА** — TT (Pt / П / М, R₀, ГОСТ 6651), PT (МПа, кгс/см², бар, psi, мм вод. ст.), FT по перепаду с корнем в датчике или в РСУ, LT прямой или гидростатикой (ρ, смещение). Ввод в любое поле пересчитывает остальные; тип прибора — по тегу (`2131-TT-434` → TT, `FT101A` → FT, KKS `10LBA10CP001` → PT); точки поверки 0/25/50/75/100 %; состояние сигнала по NAMUR NE 43.
- **Электроэнергетика** — мощность и ток (U, I, P, cosφ; 1ф/3ф; S и Q), двигатель (P₂, Iн, cosφ, η; пусковой ток, звезда → треугольник, скольжение), потеря напряжения в кабеле (сечение, длина, ток, ΔU %; медь/алюминий, AWG → мм²), учёт через ТТ/ТН (множитель, расход, средняя мощность). В каждой вкладке любые значения, кроме одного, — оно считается.
- **Переключатель разделов** — одна кнопка в шапке («Т», «Газ», «4–20», молния): касание раскрывает выбор, через 3 с он сворачивается сам.
- **«В задание»** — результат с датой и временем дописывается в задание тега (тег ищется на всех страницах, если его нет — создаётся) и уходит в отчёт.
