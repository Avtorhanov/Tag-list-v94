# Tag list

**Tag list** — лёгкое веб-приложение для работы со списками тегов.

### Возможности

- Адрес https://avtorhanov.github.io/Tag-list-v94/

- 📋 Создание и редактирование списков тегов.
- 📷 Добавление тегов из фотографии через OCR.
- ☑️ Отметка выполненных и невыполненных тегов.
- 📝 Добавление заданий к отдельным тегам.
- 📤 Показ и отправка:
  - всего списка;
  - выполненных;
  - невыполненных;
  - заданий.
- 🔤 Изменение размера и типа шрифта.
- 🌙 Переключение темы.
- 📄 Работа с несколькими страницами.
- 💾 Автоматическое сохранение данных в браузере.
- 📱 Адаптация для **iPhone и Android**.
- 📲 Возможность установить приложение на главный экран как PWA.

### Принцип работы

Приложение работает непосредственно в браузере.  
Основные данные сохраняются локально на устройстве, поэтому список можно использовать без постоянной регистрации или серверной базы данных.

### Назначение

Проект предназначен прежде всего для **быстрой работы с перечнями приборов и оборудования КИПиА** при монтаже, проверке и пусконаладочных работах.
## Обновление JSON-состояний и мобильного интерфейса
- Импорт JSON выполняется внутри приложения через «Сохранить / отправить» → «Открыть JSON»; после успешной проверки состояние сразу применяется.
- Перед заменой текущая версия сохраняется в локальном резервном ключе `kip-checklist-last-state-backup-v1`, без дополнительной загрузки резервного файла, которая мешала мобильному выбору файла.
- Отправка JSON сначала пробует системный обмен файлами, затем обмен текстом JSON, а при недоступности этих способов сохраняет файл.
- Для установленных Android Chromium PWA добавлен обработчик открытия `.json` из системного файлового менеджера. Поддержка такого открытия зависит от браузера и установки PWA; на iPhone используйте импорт внутри приложения.
- Нижняя панель выбора тегов теперь появляется выдвижением снизу; системная настройка уменьшения движения учитывается.

## v95
- **Газоанализ.** Шапка «Tag list» стала вкладкой: нажатие открывает конвертор концентраций, повторное нажатие (или «Назад», Esc) возвращает к списку.
  - ppm ⇄ мг/м³ ⇄ % об. ⇄ % НКПР ⇄ ppb ⇄ г/м³ с учётом температуры и абсолютного давления (кПа, мм рт. ст., бар; пресеты 20 °C / 0 °C / 25 °C).
  - Справочник газов для пиролиза, ПЭ/ПП и ОЗХ: молярная масса считается по формуле, НКПР — по ГОСТ 31610.20-1-2020 / ГОСТ Р 51330.19-99, ПДК р.з. токсичных газов — справочно. НКПР, M и ПДК можно заменить значениями из паспорта прибора; есть «Свой газ».
  - Доля ПДК, предупреждения о превышении ПДК и НКПР, шкала % НКПР.
  - Сигнал 4–20 мА: пересчёт ток ⇄ концентрация для любой шкалы, состояние сигнала по NAMUR NE 43, обмен значениями с основным расчётом.
  - Копирование значения касанием строки, копирование и отправка итогового результата в рабочую группу.
  - Модуль `js/gas.js` загружается по требованию и кэшируется для работы без интернета.
- **Сохранение JSON на Android.**
  - APK: данные для системного окна «Сохранить» дублируются во временный файл (не теряются, если Android выгрузил приложение), запись идёт с запасными режимами `wt → w → rwt` и проверкой размера; при неудаче пустой файл удаляется и выводится подсказка.
  - Браузер/PWA на Android: вместо системного выбора файла (на части хранилищ оставлял пустой файл) используется обычная загрузка в «Загрузки»; во встроенных браузерах мессенджеров JSON копируется в буфер обмена.
  - ПК: после записи через выбор файла проверяется, что файл не пустой, иначе — обычная загрузка.
- После открытия JSON заголовок документа сразу обновляется.
- Оптимизация без изменения интерфейса: счётчики вкладок за один проход, выборка считается только в режиме выбора, удалён неиспользуемый код.
